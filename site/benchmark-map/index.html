Benchmark map

Each cell is one slot toward 1,000 concrete tasks. A task is a curated case with a shipped input and a checkable output, large enough for a computer-use session past three hours. Purple cells are filled. Gray cells are still open. The six targets share the target evenly, so a thin target stays visible.

Shorter cases and essays stay outside this map. Tools, papers and unreviewed leads are not tasks. The three-hour line is a scope reading, not a measured run.
