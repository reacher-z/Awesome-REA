# Self-hosted fonts

These WOFF2 files are subsets of open-licensed families, served from this site so that no page depends on another origin for its type. Each family is under the [SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).

| Files | Family | Copyright |
| --- | --- | --- |
| `eb-garamond-500-core.woff2`, `eb-garamond-500-ext.woff2`, `eb-garamond-italic-display.woff2` | EB Garamond | The EB Garamond Project Authors, https://github.com/octaviopardo/EBGaramond12 |
| `ibm-plex-sans-core.woff2`, `ibm-plex-sans-ext.woff2`, `ibm-plex-mono.woff2`, `ibm-plex-mono-medium.woff2` | IBM Plex | IBM Corp., https://github.com/IBM/plex |

`scripts/review_pr.py` accepts exactly these file names; any other font added to this repository is flagged.
