# 使用数据

可通过以下公开文件和页面阅读目录、跟踪变更，或使用结构化数据。

- [llms.txt](https://awesomerea.org/llms.txt) - 供语言模型读取的网站地图。
- [llms-full.txt](https://awesomerea.org/llms-full.txt) - 汇集精选条目的单份 Markdown 文本。
- [JSON 与 CSV API](https://awesomerea.org/api/) - 资源、论文和分类的静态 JSON 与 CSV 导出文件，以及未经复核的候选条目。
- [catalog.json](https://awesomerea.org/catalog.json) - 汇集精选目录的单份 JSON 文件。
- [JSON Feed](https://awesomerea.org/feed.json) - 以 JSON Feed 格式列出新增和变更的条目。
- [Hugging Face 数据集](https://huggingface.co/datasets/AgPerry/awesome-rea) - Parquet 与 JSONL 镜像，每种记录类型一个 config，每 2 小时同步。
- [目录格式](../data/README.md) - 目录格式与字段定义。
