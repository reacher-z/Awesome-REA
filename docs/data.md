# Use the data

Use these public files and pages to read the catalog, follow changes, or work with its structured data.

- [llms.txt](https://awesomerea.org/llms.txt) - Machine-readable site map for language models.
- [llms-full.txt](https://awesomerea.org/llms-full.txt) - Curated entries in one Markdown text.
- [JSON and CSV API](https://awesomerea.org/api/) - Static JSON and CSV exports of resources, papers and categories, plus unreviewed candidates.
- [catalog.json](https://awesomerea.org/catalog.json) - Curated catalog in one JSON file.
- [JSON Feed](https://awesomerea.org/feed.json) - New and changed entries in JSON Feed format.
- [Hugging Face dataset](https://huggingface.co/datasets/AgPerry/awesome-rea) - Parquet and JSONL mirror, one config per record type, refreshed every 2 hours.
- [Catalog format](https://github.com/reacher-z/Awesome-REA/blob/main/data/README.md) - Fields, vocabulary and review rules for every record.
